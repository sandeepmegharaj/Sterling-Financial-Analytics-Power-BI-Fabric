## Key Components
*   **Data Engineering & Warehousing:** End-to-end data ingestion, transformation, and storage utilizing Microsoft Fabric Lakehouse and Data Warehouse (Delta Lake).
*   **AI Integration:** Deployment of intelligent agents and predictive models via Azure AI Foundry (utilizing Azure OpenAI Service) for advanced financial insights and natural language querying.
*   **Business Intelligence:** Interactive Power BI visualizations connected via Direct Lake mode to the Fabric Data Warehouse.

## Technologies Used

### Microsoft Fabric
*   Data Factory (Pipelines & Dataflows Gen2)
*   Synapse Data Engineering (Spark Notebooks)
*   Synapse Data Warehousing (SQL Analytics Endpoint)
*   OneLake

### Azure AI Foundry & Services
*   Azure AI Studio (Model Deployment & Agent Configuration)
*   Azure OpenAI Service (GPT-4o, Embeddings)

### Business Intelligence
*   Power BI Desktop
*   Power BI Service (Direct Lake connection)

### Languages & Database
*   T-SQL
*   Python (PySpark)
*   DAX
